# Pushpika Lakra — Cinematic Portfolio

A personal portfolio built around scroll-led storytelling rather than a static portfolio template.

## Creative direction

- Black / off-white with restrained teal-blue accents
- Cinematic scroll choreography inspired by the interaction language of premium creative portfolios
- Personal portrait used as a cinematic hero visual with subtle scroll parallax
- One real featured project: CityPulse
- Separate Achievements and Certifications sections
- Technical skills + evidence-based soft skills / how I work
- Responsive and reduced-motion aware

## Reference / attribution

The interaction direction takes inspiration from Sarang's open-source cinematic portfolio. The public reference project is MIT licensed: https://github.com/5araang/Nextjs-cinematic-portfolio

This implementation is re-authored for Pushpika's content, visual identity and information architecture rather than reproducing Sarang's branding or content.

## Run locally

```bash
npm install
npm run dev
```

Then open http://localhost:3000.

## Build

```bash
npm run build
npm run start
```

## GitHub

Recommended repository name: `pushpika-lakra-portfolio`

Do not commit `node_modules`, `.next`, local environment files or other generated artifacts.


## Hero

The hero uses Pushpika's portrait as the main visual. The image itself stays static, while the page uses subtle scroll parallax and cinematic typography transitions to keep the opening alive without pretending a still image contains body movement.
